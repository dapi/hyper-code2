R-032 is framed and its bounded comparative plan is ready for collection.

The governed package separates three evidence dimensions:

- bind/transport and modeled reachability;
- caller authentication and authorization;
- residual process authority after dispatch.

It compares loopback binding, Unix-domain socket transport,
authentication/authorization, scoped capabilities, route separation, process
separation and three predeclared layered combinations against the same fixtures.
Immediate and deferred authority, dynamic/overlay routes, browser and direct
CLI/TUI lifecycle, failure/recovery and synthetic secret non-transit all have
explicit cases and hard gates.

Collection remains static/mock/disposable-prototype only. It must not open a
listener or socket, use real secrets or user state, edit production code, or
select a mechanism. A project-wide client/server, transport,
identity/authorization or process trust-boundary selection would trigger a
separate proposed ADR before delivery.
